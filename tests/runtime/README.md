# Fresh Fiji runtime validation

This directory contains reproducible local integration tests for the aNMJ-morph+ Fiji plugin and its canonical ImageJ macro reference. The generated harnesses exercise the real Fiji/ImageJ commands while replacing only the steps that normally require manual interaction. Runtime-generated images and outputs stay under ignored `tests/runtime/_work/` rather than being committed.

The automated choices are fixed to channel 1 = muscle endplate, channel 2 = nerve terminal, ImageJ `Default dark` thresholds, three synthetic axon-width measurements, and acceptance of the stage-6 segmentation. These tests validate runtime/control flow, image/window state, CSV output, append behavior, and arbitrary-width image handling. They do not replace biological validation of manually chosen thresholds or morphology measurements.

## Run the full validation

Use a fresh Fiji installation that contains the dependencies required by aNMJ-morph+ (including Bio-Formats and `BinaryConnectivity`):

```powershell
.\tests\runtime\run_validation.ps1 -FijiRoot C:\path\to\fresh\Fiji
```

By default the runner generates fresh harnesses from `aNMJ-morph macro.txt`, runs a small deterministic fixture/metadata matrix, runs `NMJ_1.lsm` twice, creates and runs a calibrated 384 x 512 two-channel TIFF twice, and runs one additional `NMJ_1.lsm` workflow using the Java batch bridge for channel choices plus the source/template duplicate IDs. It validates:

- native `.tif` and `.tiff` opening with calibration preserved;
- uppercase `.TIF` / `.TIFF` routing;
- filenames containing spaces;
- RGB PNG opening and channel normalization;
- a real two-channel, three-plane Z stack without channel/Z reinterpretation;
- both deterministic interpretations of ambiguous `C=1/Z=2/T=1` input;
- explicit `T>1` rejection;
- completion through stage 7;
- batch-supplied channel choices, Java-created source/template duplicate IDs, and the two early Java Split Channels boundaries preserve the pinned numerical result while leaving threshold/manual and later analysis stages macro-owned;
- 29-column data rows;
- row-specific spreadsheet formulas;
- append behavior without duplicate headers or blank separator rows;
- absence of `NaN`;
- square and rectangular dimension metadata;
- all three cleaned TIFF outputs.

All synthetic fixture files are generated by the probe harness at runtime. They are intentionally small (16 x 12 pixels) and are not stored in Git.

## Java plugin smoke

After building the Maven JAR, the focused Java smoke uses the Java runtime and SciJava libraries from the pinned fresh Fiji installation to discover the plugin metadata, load the command class, and verify the exact `Analyze > Tools > aNMJ-morph+` menu path without entering any interactive scientific stage:

```powershell
.\tests\runtime\run_java_plugin_smoke.ps1 `
  -FijiRoot C:\path\to\fresh\Fiji `
  -PluginJar .\target\anmj-morph-plus-0.1.0-SNAPSHOT.jar
```

This verifies the built JAR can load and register against the exact Fiji runtime used by CI; the numerical oracle remains the authoritative guard for the macro-owned scientific workflow.

The fresh-Fiji suite also runs two headless source-copy bridge fail-closed probes using a tiny native TIFF fixture. One supplies an unresolved `source-copy-id`; the other supplies an open image whose title does not match the required `__aNMJ_source_<id>` title. Both execute the production macro parser, require the exact `Error: Invalid source-copy-id supplied by Java` exit branch, prove the legacy fallback duplicate was not entered, and verify the pinned Fiji runtime is fully cleaned up afterward.

## Pinned NMJ_1 numerical oracle

`nmj1_numeric_baseline.json` pins the automated `NMJ_1.lsm` seven-stage output. It records the reference-image SHA-256, the normalized production-macro SHA-256, the deterministic automation choices, the runtime stack used to capture the baseline, and expected values with explicit absolute tolerances for key measurements and connectivity counts.

The current oracle was captured with ImageJ 1.54p and Bio-Formats 8.5.0 using channel 1 as muscle endplate, channel 2 as nerve terminal, `Default` thresholds, synthetic axon-width lines of 10/12/8 pixels, and stage-6 acceptance. The retained output was captured at commit `756cbeb`; commit `71440db` later changed only extension-routing structure, and the production macro is unchanged between `71440db` and the current pinned base `4e05a55`. A scientific-algorithm change or intentional runtime-stack change may require updating the oracle; that update should be reviewed as a deliberate numerical behavior change rather than regenerated automatically.

CI verifies the baseline provenance against the committed `NMJ_1.lsm` and normalized macro bytes even though CI does not run Fiji.

To validate another macro build without copying it into the repository, pass `-MacroPath`:

```powershell
.\tests\runtime\run_validation.ps1 `
  -FijiRoot C:\path\to\fresh\Fiji `
  -MacroPath C:\path\to\aNMJ-morph-plus.ijm
```

Generated files live under `tests/runtime/_work/` and are intentionally ignored by Git. The PowerShell runner launches the validation Fiji process with a hidden window; it does not use desktop control, mouse/keyboard automation, or screenshots.

For a true headless check that never creates ImageJ windows, run the native TIFF subset:

```powershell
.\tests\runtime\run_headless_fixture_probe.ps1 -FijiRoot C:\path\to\fresh\Fiji
```

This headless subset covers `.tif`, `.tiff`, uppercase `.TIF`/`.TIFF`, spaces in filenames, channel dimensions, bit depth, and TIFF calibration. The RGB PNG case is routed through Bio-Formats; Bio-Formats does not materialize that image in this Fiji build under `--headless`, so RGB plus the remaining Z/C/T normalization cases stay in the hidden GUI-capable full runner rather than being falsely reported as headless coverage.

## CI scope

GitHub Actions runs the integration harness on a pinned fresh Windows Fiji build whenever the production macro, Java sources, Maven project, or runtime tests change. The workflow verifies the Fiji archive checksum, installs the pinned Morphology/BinaryConnectivity dependency, builds and smoke-tests the Java plugin JAR in that fresh Fiji installation, runs the deterministic fixture matrix, two square analyses, and two rectangular analyses, then checks the pinned numerical oracle plus CSV/TIFF outputs. The lightweight repository workflow also verifies harness/probe generation and baseline hashes without launching Fiji.

Fresh-Fiji CI also runs hidden/headless fail-closed probes for both the source-copy and template-copy bridges. Each probe covers a present unresolved ID and a present wrong-title ID, asserts the exact production parser error, rejects legacy fallback execution, and verifies Fiji cleanup.

The early Split Channels bridge has separate hidden fail-closed probes for the original and template split sites. Each forces the selected Java call to fail after the Java path was explicitly requested, requires the production Java error branch, and proves the corresponding legacy `Split Channels` fallback does not run.

## Focused probes

`probes/` contains smaller ImageJ macros for diagnosing metadata and image-selection behavior independently of the full seven-stage workflow.
